Rebuild recommendations from the same outlooks shown on cards.

Acceptance tests precede implementation: cold start, % refresh after a cached forecast, confirmed starter and bench, absent player on an announced side, unannounced opposite side, moved/wrong game, malformed eleven, source failure, expiry and navigation retention. Check both extension allowlists. Run the local gate, Arcade browser spec and real-data desktop/mobile checks in the owner's Chrome. Record actual live source coverage and remaining limits before shipping.
