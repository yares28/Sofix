What each piece costs

per run

A warm run is 140–180 calls in 1–3 minutes: the cut-offs of past gameweeks and a finished gameweek's replay are kept in the database, so a run only fetches what it doesn't already know. A cold run — first time, or after the payload changes shape — is about 1,000 calls in 10 minutes. The whole Sorare state is 172 KiB; recording the projections adds roughly 2 MB a season.

Why not just a timestamp

the three states

Fresh — the plan was built after Sorare's latest projections, and another run lands before the lock. Nothing to do.
Moved — Sorare has changed its projections since this plan was built. The plan still shows, dimmed, with the time it will rebuild itself; you can start it now if you don't want to wait.
Not in the cloud — the scheduled job hasn't written Sorare data (no key in the repository, or it failed). In both of the last two the plan stays on screen but dimmed behind the warning: you can still read it, and you can't mistake it for current.
